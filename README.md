## Metadata Included in Each Game File

Each game is stored in standard Portable Game Notation (`.pgn`) format with full metadata:
- **Players**: `[White "..."]` and `[Black "..."]`
- **Date/Time**: `[Date "YYYY.MM.DD"]`
- **Result**: `[Result "1-0" | "0-1" | "1/2-1/2"]`
- **Game Length in Moves**: `[MoveCount "<N>"]`, `[PlyCount "<P>"]`, and `[GameLength "<N> moves (<P> ply)"]`
- **Context**: `[Event "..."]`, `[Site "..."]`, `[Round "..."]`, and `[ECO "..."]`
- **Move Text**: Complete SAN move sequence.
